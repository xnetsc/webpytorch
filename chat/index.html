Pick “custom” to load any other ModelScope model, or one of the “on this device” entries to load a model file/folder straight from disk — nothing is copied or cached.

GPU memory is estimated from system RAM — right for unified memory (Apple silicon, phones, integrated GPUs), too high for a discrete GPU whose VRAM is smaller. Set it to your card’s VRAM if you have one. Context length is everything the model holds at once, conversation plus reply. Left empty it follows the size the model itself declares, trimmed if its KV cache would not fit; applies the next time a model loads.

Left empty, a reply may run as long as the model allows — up to the rest of the context length; the model still stops itself when it is done. A number sets a hard stop instead. A model told to think spends part of any budget on the thinking, so a low limit can end the answer before it starts; a reply cut short by the limit says so.

Off by default: the model answers directly. On: the reasoning is written first and shown folded away — slower, and it shares the reply budget above. Only models whose chat template knows the option do anything with it.
